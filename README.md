# Software para Gerenciamento de Petshop

Sistema web para gerenciar um petshop, com cadastro de clientes, funcionários, animais e atendimentos.

Trabalho da disciplina de Programação de Sistemas Web (UEM).

## Tecnologias

- HTML
- CSS
- Bootstrap 5.3
- JavaScript (apenas no botão de imprimir e na confirmação de remoção)

## Funcionalidades

Cada entidade (Cliente, Funcionário, Animal e Atendimento) tem as páginas de:

- Cadastro
- Consulta
- Alteração
- Remoção
- Relatório

Nesta primeira parte os formulários ainda não salvam dados, e os relatórios mostram dados de exemplo.

## Como executar

Basta abrir o arquivo `index.html` no navegador (é preciso internet para carregar o Bootstrap).
